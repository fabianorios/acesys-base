# Shape files for acesys-base

## One-time setup

1. Copy this whole folder’s contents into `C:\Users\fabia\agents\acesys-base` (overwrite `bot/`, `evals/`, and the `.bat` files).
2. Delete `bot\tools\echo.ts` if it still exists.
3. Double-click **`setup.bat`** (npm + firebird + validate).

## Every day you use the agent

Double-click **`start.bat`** → open `http://127.0.0.1:3000/playground`.

No re-init. No manual `npx` chain unless you change code.
